Anonymous requests use a server-signed random thirty-minute bearer token stored only in JS memory; no ambient cookie, login, user0nonce, administrator token or localStorage authority is used. Because there is no ambient authority or personalized write, the earlier review's cookie-plus-CSRF proposal was replaced with cookie-less bearer admission, origin/Sec-Fetch-Site checks and credential-omitting fetches. Foreign browser origins are denied even though WordPress normally adds permissive REST CORS headers. Nonbrowser clients can obtain tokens intentionally but remain subject to hashed peer/session/global caps.

No prompt or response text is logged by this plugin; provider/host logs are outside that promise. Google key stays in the existing site's option and is never copied between sites. The request ceiling is not a currency-denominated billing limit.
