# Visitor pilot launch

User explicitly requested production publication on6November2026. This standalone plugin reuses three exact tested core domain files and never opens administrator preview/Service/abilities to visitors. Pilot scope is immutable program13/MDG10 (İzmir); fresh bridge/status/time/native-product/family checks apply on every catalogue/quote. The event expires normally and no other event is substituted.

Master option `mdg_vp_enabled` and independent AI option `mdg_vp_ai_enabled` both default0. Public page `/bilet-onerisi/` and routes are enabled only on the exact production/staging origins. The native Bilet Al page receives a plain entry link via a scoped content filter. No native cart/order/payment handler is modified. Link handoff uses the canonical event URL plus fixed#bilet-secimi, with explicit instructions to reselect session and quantities. Quotes expire within60seconds.

Anonymous requests use a server-signed random thirty-minute bearer token stored only in JS memory; no ambient cookie, login, user0nonce, administrator token or localStorage authority is used. Because there is no ambient authority or personalized write, the earlier review's cookie-plus-CSRF proposal was replaced with cookie-less bearer admission, origin/Sec-Fetch-Site checks and credential-omitting fetches. Foreign browser origins are denied even though WordPress normally adds permissive REST CORS headers. Nonbrowser clients can obtain tokens intentionally but remain subject to hashed peer/session/global caps.

Bootstrap:20/IP/minute and2000global/day. Catalogue/quote/parse general admission:30/session/minute,60/IP/minute and3000global/day. Gemini:5/session/5minutes,10/IP/10minutes,50global/day,one active model call,512output tokens,30second timeout,16KiB response,zero redirects. IP uses REMOTE_ADDR and never arbitrary forwarded headers; shared proxy peers can conservatively share a limit. Only HMAC identifiers and expiring counters persist. No prompt or response text is logged by this plugin; provider/host logs are outside that promise. Google key stays in the existing site's option and is never copied between sites. The request ceiling is not a currency-denominated billing limit.

Rate accounting is serialized; own option locks use leases and compare-and-delete ownership so crashed leases can be recovered without releasing a new owner's lock. Only technical lock/transient options are written. No reservations/holds/orders/payment/customer records are accessed by the new controller. Gemini only returns validated city/count fields; unknown fields remain null and user review/session selection are explicit. Manual comparison works with AI disabled or unavailable.
