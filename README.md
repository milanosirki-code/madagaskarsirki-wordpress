# Madagaskar Sirki WordPress

Madagaskar Sirki yönetim modüllerinin kaynak kod deposu.

## Modüller

- Okul Tanıtım Yönetimi
- MEB kurum listesi içe aktarma ve temizleme
- Tanıtım personeli görev takibi
- Google Maps rota planlama

Geliştirmeler önce ayrı dallarda hazırlanır ve kontrol sonrasında ana dala alınır.
